## 🚀 Быстрый старт

### 1. Лендинг (HTML)
Лендинг готов к использованию! Просто откройте `garant-sdelok-3.0.html` в браузере или импортируйте в Tilda.

**Особенности лендинга:**
- ✅ Размер < 22 КБ
- ✅ SEO-оптимизирован
- ✅ Адаптивный дизайн
- ✅ AI-калькулятор рисков
- ✅ Реферальная система
- ✅ Виральные механики

### 2. Telegram-бот

#### Установка зависимостей:
```bash
pip install -r requirements.txt
```

#### Настройка:
1. Скопируйте `.env.example` в `.env`
2. Получите токен бота у @BotFather
3. Заполните конфигурацию в `.env`

#### Запуск:
```bash
python telegram_bot.py
```

**Функции бота:**
- 🎮 Геймифицированный онбординг
- 🤖 AI-анализ сделок
- 🎨 Генерация NFT-сертификатов
- 💰 Реферальная система
- 📊 Персонализированная статистика

### 3. AI-система

```bash
python ai_integration.py
```

**Возможности AI:**
- Анализ рисков сделок
- Конструкция схем сделок
- Генерация NFT-сертификатов
- Персонализация рекомендаций

### 4. Виральные механики


**Функции:**
